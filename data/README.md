# Datenstruktur

- `data/raw/`: Unveränderte Eingangsdaten (z. B. Rohantworten, externe CSVs).
- `data/processed/`: Vorverarbeitete Daten (bereinigt, normalisiert), direkt für Analysen.
- `data/meta/`: Schemas, Manifeste, Mappings.

Bitte keine personenbezogenen Daten ablegen. Nur anonymisierte oder aggregierte Inhalte.
