# Palette's Journal - UX & Accessibility Learnings

This journal documents critical learnings about this specific codebase's UX patterns, accessibility challenges, and design system constraints.

## 2024-05-24 - Initial Discovery
**Learning:** The project uses a mix of Streamlit (Python) and vanilla JS/Leaflet for the map interface. The map interface (`web/5d-map`) lacks basic accessibility features like "Skip to content" and visible focus indicators.
**Action:** Implement "Skip to content" link and improve focus styles in `web/5d-map`.
