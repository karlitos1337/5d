## 2024-05-14 - CI Failures and Missing Dependencies
**Learning:** Python projects often have linting scripts in CI that flag invalid syntax, but testing this locally requires all dependencies like `flake8` to be installed. Also, CI may run checks in a way that requires fixing the original submodules (like `external/system-genesis`). Furthermore, if a 3rd-party action no longer exists (e.g. `apisec-inc/ethicalcheck-action`), the workflow using it will break and might need to be removed or updated if the owner deleted it.
**Action:** When debugging CI failures involving `flake8` syntax errors, make sure to read the specific line mentioned, make the fix, and then run `flake8` locally. If an action is missing and breaking the build, delete the workflow file if it's no longer resolvable.
