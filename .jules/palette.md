## 2026-05-18 - Keyboard accessibility and ARIA improvements in React Apps
**Learning:** When building React applications using manual dark mode state management (via \`useState\`) instead of standard class-based setups, applying Tailwind's \`focus-visible\` classes for keyboard accessibility requires special attention to contrast. Icon-only buttons also often lack ARIA attributes, creating accessibility barriers.
**Action:** When adding \`focus-visible:ring\` classes, always include \`focus-visible:ring-offset\` classes dynamically with template literals based on the \`darkMode\` state (e.g. \`${darkMode ? 'focus-visible:ring-offset-gray-900' : 'focus-visible:ring-offset-white'}\`) to preserve contrast. Also add \`aria-label\` and \`title\` to icon-only buttons, and \`aria-expanded\` to mobile menu toggles to enhance accessibility for screen readers.
