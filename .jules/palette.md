## 2024-05-19 - Improved Keyboard Navigation Focus Indicators
**Learning:** Found multiple icon-only buttons (like Dark Mode toggle and Mobile Menu) that lacked `aria-label`s, breaking screen reader experience. Additionally, many interactive elements lacked keyboard focus states, making keyboard navigation difficult to follow visually. A bug duplication of the `sections` array and syntax error within the `useEffect` scroll handler caused lint and run failures.
**Action:** When adding interactive buttons, ensure all icon-only buttons have an explicit descriptive `aria-label`. Use the `focus-visible:` tailwind utility (`focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-blue-500`) to add accessible focus indicators solely for keyboard users, preventing visual clutter for mouse users. Fixed duplicate variables and ESLint errors to ensure stability.
