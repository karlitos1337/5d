## 1. Theoretische Grundlage

### 1.1 Konstrukt

Das 5D-DPI misst **nicht** kognitive Fähigkeit (wie IQ), sondern die **dominante kognitive Orientierung** eines Individuums — d.h. welche der fünf Intelligenzdimensionen im Alltag am stärksten aktiviert wird. Jeder Mensch hat alle 5 Dimensionen, aber in unterschiedlicher Ausprägung.

### 1.2 Die 5 Dimensionen

| Dim | Name | Neurobiologische Basis | Kognitive Orientierung | Messfokus |
|-----|------|----------------------|----------------------|-----------|
| **1D** | Sicherheits-Intelligenz | Hirnstamm, Amygdala | Gefahrenerkennung, Musterwarnung, Instinkt | "Ich merke sofort wenn etwas nicht stimmt" |
| **2D** | Regulations-Intelligenz | Limbisch + PFC | Planung, Impulskontrolle, Strategisches Denken | "Ich denke nach bevor ich handle" |
| **3D** | System-Intelligenz | Integrierter PFC, Theory of Mind | Empathie, Systemerkennung, Perspektivwechsel | "Ich sehe wie alles zusammenhängt" |
| **4D** | Netzwerk-Intelligenz | Dezentrale Netzwerke | Kollaboration, Vernetzung, Emergenz-Erkennung | "Zusammen lösen wir mehr als allein" |
| **5D** | Gestaltungs-Intelligenz | Meta-Kognition, Default Mode | Systemtransformation, Visionäres Denken, Realitätsgestaltung | "Das System selbst muss sich ändern" |

### 1.3 Abgrenzung zu existierenden Instrumenten

| Instrument | Misst | Unterschied zu 5D-DPI |
|-----------|-------|----------------------|
| KAI (Kirton, 1976) | Adaption vs. Innovation | Eindimensional (Kontinuum), kein Dimensionsprofil |
| CoSI (Cools & Van den Broeck, 2007) | Knowing, Planning, Creating Style | 3 Stile, keine neurobiologische Verankerung |
| ATCDS (Frontiers, 2021) | Team-Diversität (4 Faktoren) | Team-Level, nicht Individual-Profil |
| MBTI | 4 Präferenzpaare | Keine empirische Validität ([Pittenger, 2005](https://doi.org/10.1177/1073191105276231)), nicht falsifizierbar |
| Big Five (IPIP-NEO-120) | 5 Persönlichkeitsfaktoren | Misst Trait-Disposition, nicht kognitive Orientierung |

**5D-DPI ist neu weil:** Es verbindet neurobiologische Hierarchie (1D→5D) mit kognitiver Selbsteinschätzung in einem Profil-Instrument, das Gruppenkomposition vorhersagen soll — nicht individuelle Leistung.

## 3. Scoring: Dominanzprofil

### 3.1 Rohwert-Berechnung

```python
# Pro Subskala: Summenscore (Range: 5-25, Mittelwert: 15)
score_1D = sum(items[1:6])
score_2D = sum(items[6:11])
score_3D = sum(items[11:16])
score_4D = sum(items[16:21])
score_5D = sum(items[21:26])
```

### 3.2 Normierung (Z-Score)

```python
import numpy as np

scores = [score_1D, score_2D, score_3D, score_4D, score_5D]
z_scores = (np.array(scores) - np.mean(scores)) / np.std(scores)
```

### 3.3 Dominante Dimension

```python
dominant_dim = np.argmax(z_scores) + 1  # 1D, 2D, 3D, 4D, oder 5D
```

### 3.4 Profil-Visualisierung (Radarplot)

```python
import matplotlib.pyplot as plt

labels = ['1D Sicherheit', '2D Regulation', '3D System', '4D Netzwerk', '5D Gestaltung']
angles = np.linspace(0, 2*np.pi, len(labels), endpoint=False).tolist()
angles += angles[:1]  # Close the plot

values = z_scores.tolist()

fig, ax = plt.subplots(figsize=(6,6), subplot_kw=dict(polar=True))

ax.set_title('5D-Dimensionsprofil')
```

## 4. Keimzellen-Matching

### 4.1 Funktionale Vollständigkeit einer Gruppe

Gegeben eine Gruppe G = {p₁, p₂, ..., pₙ}:

```python
def ist_funktional_vollstaendig(gruppe_profile):
    """
    Prüft ob alle 5 Dimensionen mindestens einmal dominant vertreten sind.
    
    gruppe_profile: Liste von dominanten Dimensionen [1, 3, 5, 2, 4]
    Returns: True wenn alle 5 Dimensionen vertreten
    """
    return len(set(gruppe_profile)) == 5

# Beispiel:
profil_gruppe = [1, 3, 5, 2, 4]  # Jede Dim einmal → vollständig
print(ist_funktional_vollstaendig(profil_gruppe))  # True

profil_gruppe_2 = [5, 5, 3, 5, 3]  # Nur Dim 3 und 5 → unvollständig
print(ist_funktional_vollstaendig(profil_gruppe_2))  # False
```

### 4.2 Komplementaritäts-Score

Über die reine Vollständigkeit hinaus: Wie gut ergänzen sich die Profile?

```python
def komplementaritaets_score(profile):
    """
    Misst die Komplementarität einer Gruppe.
    0 = alle identisch, 1 = perfekt komplementär
    
    profile: Liste von 5D-Vektoren (z-scores) je Gruppenmitglied
    """
    n = len(profile)
    # Korrelationsmatrix aller Profilpaare
    korrelationen = []
    for i in range(n):
        for j in range(i+1, n):
            r = np.corrcoef(profile[i], profile[j])[0,1]
            korrelationen.append(r)
    
    # Niedrige Korrelation = hohe Komplementarität
    mittlere_korrelation = np.mean(korrelationen)
    return (1 - mittlere_korrelation) / 2  # Normiert auf [0, 1]
```

## 5. Validierungsstrategie

### 5.1 Interne Konsistenz (Pilot, n=50)

| Kriterium | Schwelle | Methode |
|-----------|----------|---------|
| Cronbach's α pro Subskala | ≥ 0.70 | `reliability()` in R / `pingouin` in Python |
| Inter-Item-Korrelation | 0.20–0.60 | Korrelationsmatrix |
| Item-Total-Korrelation | ≥ 0.30 | Corrected item-total |

### 5.2 Faktorstruktur (Hauptstudie, n≥200)

| Test | Erwartung | Methode |
|------|-----------|---------|
| Explorative Faktorenanalyse (EFA) | 5 Faktoren mit Eigenvalue > 1 | Principal Axis, Oblimin-Rotation |
| Konfirmatorische Faktorenanalyse (CFA) | CFI ≥ 0.90, RMSEA ≤ 0.08, SRMR ≤ 0.08 | lavaan (R) / semopy (Python) |
| Faktor-Korrelationen | < 0.70 (diskriminant) | CFA inter-factor correlations |

### 5.3 Konvergente und Diskriminante Validität (n≥200)

| 5D-Subskala | Konvergent mit (r ≥ 0.30) | Diskriminant von (r < 0.20) |
|-------------|---------------------------|----------------------------|
| 1D Sicherheit | NEO Neurotizismus-Vulnerability | NEO Extraversion |
| 2D Regulation | NEO Gewissenhaftigkeit | NEO Offenheit |
| 3D System | RME (Baron-Cohen), NEO Verträglichkeit | NEO Neurotizismus |
| 4D Netzwerk | NEO Extraversion-Gregariousness, SNI | NEO Neurotizismus-Vulnerability |
| 5D Gestaltung | NEO Offenheit, NCS, KAI Innovation | NEO Gewissenhaftigkeit |

### 5.4 Kriteriumsvalidität (n≥100, Gruppenebene)

**Hypothese:** Funktional vollständige Gruppen (alle 5 Dimensionen vertreten) lösen diverse Problemsets besser als funktional unvollständige Gruppen.

| Design | Messung | Erwartung |
|--------|---------|-----------|
| 20 Gruppen à 5–8 Personen | Problemlösung (diverse Tasks, à la Woolley 2010) | d ≥ 0.50 für vollständige vs. unvollständige |
| DPI → Gruppenzuordnung | Kollektive Intelligenz (c-Faktor) | r ≥ 0.30 zwischen Vollständigkeit und c |
| Pre/Post-Design | Lerntransfer nach 1 Woche | Vollständige Gruppen: höhere Retention |

### 5.5 Test-Retest-Reliabilität (n≥50, Abstand: 4 Wochen)

| Kriterium | Schwelle |
|-----------|----------|
| ICC (Individual-Level) | ≥ 0.70 |
| Dominante Dimension stabil | ≥ 80% gleiche Dimension nach 4 Wochen |

## 6. Ethik und Grenzen

### 6.1 Das Instrument misst NICHT:

- Intelligenz (es gibt keine "bessere" Dimension)
- Pathologie (1D-Dominanz ≠ Angststörung)
- Leistungsfähigkeit (hoher Score ≠ hohe Leistung)
- Unveränderbares Trait (Profile verschieben sich kontextabhängig)

### 6.2 Missbrauchsrisiken:

| Risiko | Mitigation |
|--------|-----------|
| Ranking von Menschen nach Dimension | Expliziter Disclaimer: "Alle Dimensionen sind gleichwertig" |
| Selektion/Diskriminierung | Instrument nur für Gruppen-Matching, nie für Individual-Bewertung |
| Stigmatisierung (z.B. "Du bist nur 1D") | Profil zeigt ALLE 5 Werte, nicht nur den dominanten |
| Manipulation durch Social Desirability | Reverse Items einbauen (v2.0), Anonymität garantieren |

### 6.3 Bekannte Schwächen v1.0:

1. **Keine Reverse Items** — Erhöht Risiko von Acquiescence Bias (Ja-Sager-Tendenz). In v2.0 beheben: 2-3 Reverse Items pro Subskala.
2. **Selbstbericht** — Kognitive Orientierung per Selbstauskunft ist anfällig für Self-Enhancement. Ergänzung durch Behavioral Assessment in v2.0 erwägen.
3. **Neurobiologische Verankerung** — Die Zuordnung 1D→Hirnstamm, 2D→Limbisch etc. ist vereinfacht. Die reale Neurobiologie ist weniger hierarchisch. Disclaimer in Instruktion.
4. **Kulturabhängigkeit** — Items wurden auf Deutsch entwickelt. Übersetzung benötigt kulturelle Adaptation (nicht nur Sprachübersetzung), besonders für Items wie "Bauchgefühl" (1D_4) und "Netzwerk vs. Einzelkämpfer" (4D_4).
