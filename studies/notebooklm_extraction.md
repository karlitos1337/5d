### 3.1 Angst und Mut – Taxonomische Handlungsgleichung

**Question:** Wie hängen Angst und Mut damit zusammen? Und welchen Wert bekommt dann Interpretation?

**Answer:**
- Angst und Mut sind im 5D-Framework keine moralischen Konzepte, sondern der evolutionäre neurobiologische Nenner der jeden Entscheidung filtert.
- **Mut (Annäherung / 1):** Energetische Expansion ("hin zu"). Gesteuert durch das dopaminerge SEEKING-System. Existiert ausschließlich im absoluten Jetzt.
- **Angst (Vermeidung / 0):** Energetische Kontraktion ("weg von"). Gesteuert durch Amygdala und Cortisol/Adrenalin. Speist sich aus vergangenen Traumata und projiziert Sorgen in die Zukunft.

**Drei Modi der Interpretation:**
1. **Angstdominierter Modus (1D-Regression):** Angst = absolute Wahrheit, Mut = Dummheit. Erzwingt übermäßige Amygdala-Aktivierung.
2. **Toxisch-mutiger Modus:** Angst = Schwäche, Mut = immer durchziehen. Führt zu Selbst- oder Fremdgefährdung.
3. **Regulierter 5D-Modus:** Mut ist nicht die Abwesenheit von Angst, sondern wertbasiertes Handeln trotz Angst. Angst = prüfbares Signal.

**Epistemologischer Wert:** Die bewusste, radikal ehrliche Interpretation ist selbst die primäre Messeinheit (Qualia). Je ehrlicher das System nach innen kalibriert ist, desto souveräner wird das Individuum.

### 3.5 IMP-Formel und Geometrische Falsifikations-Logik

**IMP-Formel (Geometrisches Mittel):**

```
IMP = (A · IM · R · SP · Au)^(1/5)
```

**Variablen:**
- **A** = Autonomie
- **IM** = Intrinsische Motivation / Kompetenz
- **R** = Resonanz
- **SP** = Soziale Partizipation (SP)
- **Au** = Authentizität

**Stark multiplikative Version (Strict Mode):**
```
IMP = A · C · R · P · Au
```

**Erweiterung mit Polyvagal-Boost:**
```
IMP = (A · IM · R · SP · Au)^(1/5) mit Vagal-Exponent
```

**Taxonomische Handlungsgleichung (mit Nenner):**
```
Φ₅D = (A · C · R · P · Au) / (Maskierungs-Entropie + Zwang)
```

**Geometrisches Mittel (Falsifikations-Logik):**
- Löst das Zero-Inflation-Problem: Statt reiner Multiplikation (Werte 0–1) → 0,5^5 = 0,031
- Geometrisches Mittel: 0,5^(5/5) = 0,5 → linearer Wertebereich
- Weak-Link-Logik bleibt erhalten: Fällt Autonomie auf Null → Gesamtergebnis = Null
- Macht das Modell für konfirmatorische Faktorenanalyse (CFA) und OSF-Falsifikationstests anwendbar

**"Trojanisches Pferd" Prinzip:** Mathematische Anpassung erlaubt empirischen Test in OSF-präregistrierten Studien (N>400), ohne die Weak-Link-Logik aufzugeben.
