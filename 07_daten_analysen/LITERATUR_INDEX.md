## 🔬 Evidenzlabel-System

Jede Quelle wird kategorisiert:

| Label | Bedeutung | Kriterien |
|-------|-----------|-----------|
| ✅ **Fakt** | Peer-reviewed, repliziert, empirisch validiert | Mind. 3 unabhängige Studien |
| ⚠️ **Hypothese** | Plausibel, testbar, noch nicht validiert | Theoretisch fundiert, falsifizierbar |
| 🔮 **Spekulation** | Explorativ, spekulativ, offene Frage | Keine empirische Basis (yet) |

**Beispiele:**
- SDT (Deci & Ryan 1985): ✅ Fakt (1000+ Studien, Meta-Analysen)
- IMP-Formel (A × IM × R × SP × Au): ⚠️ Hypothese (eigene Modellierung, testbar)
- 5D als spatio-temporales Netzwerkmodell: 🔮 Spekulation (konzeptuell, noch nicht operationalisiert)

## 📋 Zitierstil

**Standard:** APA 7th Edition (konsistent mit BibTeX)

**Inline-Zitate:**
```markdown
Laut Deci & Ryan (1985) fördert Autonomie intrinsische Motivation [@deci1985intrinsic].
```

**Literaturverzeichnis:**
```
Deci, E. L., & Ryan, R. M. (1985). Intrinsic motivation and self-determination in human behavior. 
Springer Science & Business Media. https://doi.org/10.1007/978-1-4899-2271-7
```

**In Code/Tests:**
```python
# Scientific reference: Deci & Ryan 1985 (Self-Determination Theory)
# BibTeX key: deci1985intrinsic
assert autonomy > 0.5, "SDT requires autonomy > 0.5 (Deci & Ryan 1985)"
```

## 🧪 Integration mit Tests

Alle wissenschaftlichen Behauptungen in Tests müssen mit BibTeX-Keys verknüpft sein:

```python
# tests/test_imp_scientific.py
def test_realistic_5d_model():
    """
    Test IMP with realistic alternative education scores.
    
    Scientific Basis: Sudbury Valley School, Folk High Schools, Tokkatsu
    References: greenberg1992legacy, nielsen1989danish, lewis1995educating
    
    Expected: 0.95 × 0.88 × 0.82 × 0.79 × 0.91 ≈ 0.4928
    """
    dimensions = {'A': 0.95, 'IM': 0.88, 'R': 0.82, 'SP': 0.79, 'Au': 0.91}
    result = calculate_imp_verified(dimensions)
    
    assert abs(result['raw_multiplicative'] - 0.4928) < 0.01
    assert result['formula_used'] == 'A × IM × R × SP × Au'
```

**Validation:** Tests automatisch mit BibTeX abgleichen:
```bash
pytest tests/test_imp_scientific.py --bibtex-check
```

## 🔄 Aktualisierungs-Workflow

1. **Neue Quelle identifizieren** (Paper, Buch, Report)
2. **BibTeX-Eintrag erstellen** (Tool: https://www.bibtex.com/c/bibtex-generator/)
3. **In `5d-relevant-sources.bib` einfügen** (alphabetisch nach Key)
4. **Kategorie zuweisen** (Neuro, Öko, Governance, etc.)
5. **Evidenzlabel vergeben** (✅ Fakt, ⚠️ Hypothese, 🔮 Spekulation)
6. **Tests aktualisieren** (falls relevant)
7. **Commit** mit Nachricht: `docs: add [Author Year] to BibTeX (Category)`

**Beispiel-Commit:**
```bash
git add 07_daten_analysen/5d-relevant-sources.bib
git commit -m "docs: add Pearl 2009 (Causality) to BibTeX (Kausalmodelle)"
```

## 🆘 Troubleshooting

### "BibTeX-Key not found"
- Prüfe Schreibweise (case-sensitive!)
- Suche in `5d-relevant-sources.bib` mit `grep`
- Falls fehlt: Issue erstellen mit Template `.github/ISSUE_TEMPLATE/research_*.md`

### "Duplicate entry"
- Merge mit vorhandenem Eintrag
- Bevorzuge älteres Paper (Originalquelle)
- Neueres als `@incollection` mit `crossref` verlinken

### "Paywall / kein Zugriff"
- Prüfe Open Access Alternativen (Preprint, Author's Copy)
- Nutze Library Genesis, Sci-Hub (nur für Forschung!)
- Falls kritisch: Inter-library loan anfragen
